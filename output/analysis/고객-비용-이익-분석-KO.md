## 1. 고객이 치르는 것 — 세 겹

고객 CFO 가 보게 될 비용은 구독료 하나가 아니라 **세 겹**입니다. 영업이 첫 겹만 말하면 둘째·셋째 겹이 계약 뒤에 나타나서 신뢰를 깎습니다. 먼저 다 적습니다.

### 1.1 구독료 — 우리에게 내는 돈 (미정)

가격은 미정이고, 정할 때 쓸 앵커만 놓습니다. 기준은 **그 회사의 연간 치과 지출 대비 비중**입니다.

연간 치과 지출 풀 `[산술: 가입자 22,000 × 12개월 × PMPM $31.4 [정본]]`:

```
시나리오 A  연 $8,289,600
```

| 구독료 (PEPM) | 연간 | 지출 대비 | 읽는 법 |
|---:|---:|---:|---|
| $0.5 | $60,000 | 0.72% | 지출의 1% 미만 — "반올림 오차" 영역 |
| $1 | $120,000 | 1.45% | 절감으로 정당화하려면 지출을 1.45% 움직여야 |
| $2 | $240,000 | 2.90% | 웰니스 포인트솔루션 상단 `[추측]` |
| $3 | $360,000 | 4.34% | 이 지점부터는 성과 증빙 요구가 붙을 것 `[추측]` |

**과금 축의 선택지 둘, 하나는 위험합니다.**

- **참여 기반(Activated 인원당)** — 방어 가능. 참여는 우리가 만드는 것이고 세는 방법이 정본에 있습니다.
- **완료 기반(완료 확인 건당)** — **위험.** 완료 확인은 발생 확인이지 인과가 아니므로, **어차피 갈 사람의 방문에 과금**하는 구조가 됩니다. 고객 쪽 분석가가 이걸 발견하는 순간 가격 전체가 의심받습니다.

### 1.2 도입 비용 — 우리에게 내지 않는 돈 (구독료보다 클 수 있음)

전부 고객의 내부 비용이고, 착수 게이트 여섯과 온보딩 절차에서 그대로 나옵니다.

| 항목 | 내용 | 규모 |
|---|---|---|
| 법무 검토 | 착수 차단 게이트 **6건** 서면 종결 + 법무 레지스터 **23항목** 중 해당분. HIPAA 역할 판정이 가장 무겁고, **캘리포니아 CMIA(§16-23)가 그 판정과 무관하게 별도로 붙는다** | 외부 자문 수십 시간 `[추측]` |
| TPA 협조 | claim-line 추출 셋업. **TPA 가 데이터 추출에 수수료를 청구하는 관행이 있다** `[추측]`. 리전이 맞으면 Secure Data Sharing 으로 줄고, 아니면 SFTP 구축 | TPA 계약 조건에 따라 0 ~ 상당액 |
| HR·IT | 834 피드 연결, **부서 파일 별도 제공**(834 에 부서가 없음 — 정본이 결함으로 등록한 항목), 보안 검토 세션 | 내부 인력 시간 |
| 임직원 커뮤니케이션 | 프라이버시 설명 포함 롤아웃. **선택 항목이 아님** — 참여가 프로그램의 성립 조건이고, 감시로 읽히는 순간 참여가 죽는다 | 내부 인력 시간 + 자료 제작 |

**2026-08-31 갱신 — 게이트가 넷에서 여섯이 됐습니다.** 이 문서는 2026-08-16 에 넷으로
썼고, 2026-08-25 에 `baa_and_region` 이, 2026-08-28 에 캘리포니아 **CMIA** 가 들어와
여섯입니다. 법무 레지스터도 22 → 23 입니다. **정본이 두 번 바뀌는 동안 이 문서가 안
따라왔고**, 같은 부류로 이 저장소에서 47건이 나왔습니다 (`output/status/REVIEW-2026-08-30.md`).

**CMIA 가 고객 비용에 실제로 더하는 것.** 1차 파일럿이 캘리포니아이고, CMIA(Civil Code
§56 이하)는 HIPAA 역할 판정과 **무관하게** 붙습니다 — §56.06 이 소비자에게 의료정보를
관리하도록 설계된 소프트웨어를 제공하는 사업자를 `provider of health care` 로 간주합니다.
고객 쪽에 직접 걸리는 것은 **§56.20** 입니다: 고용주는 받은 의료정보를 고용 목적으로 쓸 수
없고, **authorization 거부를 이유로 차별할 수 없습니다.** 그래서 기업의 내부 통제 절차가
하나 더 필요하고, 그것도 고객의 시간입니다.

노출 크기가 HIPAA 와 다릅니다 — §56.35~56.36 이 **실손해 입증 없이 건당 $1,000** 과
변호사비를 주고 **사적 소권**이 있습니다. 이건 우리 리스크이기도 하지만, 계약 협상에서
고객 법무가 먼저 물을 항목입니다. **법률 자문이 아니며 법무 확인 대상입니다.**

**여기서 정직해야 할 것:** 이 겹은 우리 매출이 아니라서 영업 자료에서 사라지기 쉽습니다. 그런데 고객 입장에서는 **현금이 아니라 조직의 시간**이라 더 아픕니다 — 법무·IT·HR 세 부서의 협조를 끌어내는 일이 구독 결재보다 어렵습니다.

### 1.3 1년차 청구 증가 — J-커브 (숨기면 안 되는 겹)

**프로그램이 작동할수록 1년차 치과 청구는 늘어납니다.** 예방 진료를 늘리는 것이 목적이고, self-funded 기업은 그 청구를 그해에 자기 계좌에서 지급합니다.

데모 구조값으로 규모감만 잡으면 `[산술 × 추측]`:

```
완료 확인 420건 [정본 4.2% × 10,000명]  ×  예방·상담 방문 단가 $150–300 [추측]
= 1년차 추가 청구 $63,000–126,000  (지출의 0.8–1.5%)
```

**$1 PEPM 가정 시 1년차 고객 순지출:**

```
구독 $120,000  +  추가 청구 $63,000–126,000
= $183,000–246,000  ≈  연간 치과 지출의 2.2–3.0%
```

이 숫자의 이중성을 그대로 말해야 합니다 — **추가 청구는 프로그램이 작동했다는 증거이자 1년차 비용**입니다. 장기 회피(예방이 대형 시술을 줄인다)는 업계 통념이고 `[추측]`, 우리는 그것을 증명하지 않기로 했습니다. 즉 **1년차 현금 흐름은 마이너스가 유력하고, 이를 아는 채로 사는 고객이 우리 고객입니다.**

## 2. 고객이 받는 것 — 유형

| 받는 것 | 등급 | 비고 |
|---|---|---|
| 분기 단위 가시성 — 신호 분포·참여·완료, 부서 단위 | `[확실]` | 오늘 연 1회 사후 리포트 대비 주기·시점·행동 연결이 다름 |
| **청구로 확인된 완료 건수** — 복지가 실제로 쓰였다는 자기 데이터 근거 | `[확실]` | TPA 리포트가 구조적으로 못 만드는 열. 프로그램 존재의 정의 |
| 임직원·가족의 예방 진료 이용 증가 | `[정본 구조값]` | 실제 참여율은 미검증 — 리스크 2번 |
| 장기 비용 회피 (예방 → 대형 시술 감소) | `[추측]` | **우리가 주장하지 않는 항목.** 고객이 스스로 믿을 수는 있으나 우리 근거로 팔지 않는다 |
| (완전보험) 갱신 협상 카드 | `[추측]` | 캐리어 인정에 달림 — 리스크 9번, 근거 0건 |

**본전 산술을 고객 자리에서 해보면:** $1 PEPM 구독이 절감으로 정당화되려면 지출을 1.45% 움직여야 하는데, **우리는 그 증명을 하지 않기로 했습니다.** 따라서 구독의 정당화 경로는 절감이 아니라 **복지 + 근거 + 가시성**이어야 하고, 그 값이 연 $120,000 어치인지가 §4 의 질문입니다.

## 3. 고객이 받는 것 — 무형

| 받는 것 | 누구에게 | 비고 |
|---|---|---|
| 복지 항목 하나 추가 — 집에서 2분, 가족 포함, 무료 | 임직원 | 채용·유지 스토리에 쓸 수 있는 "새로운" 복지. 효과 크기는 `[추측]` |
| **자기 방어 근거** — "복지 예산이 실제로 쓰인다"를 자기 회사 청구로 보여줄 수 있음 | 복리후생 담당자 개인 | 이 사람이 구매자다. 갱신 비용을 억제하면 승진하고 임직원 불만이 터지면 잘리는 자리 |
| 인구집단 데이터 자산 — 캐리어·TPA 것이 아닌 첫 자가 근거 | 기업 | 갱신·플랜 설계·웰니스 예산 방어에 재사용 |
| 임직원 신뢰 — **양날** | 기업 | 프라이버시 설계가 지켜지면 신뢰 자산. **감시로 읽히면 부채가 되고 프로그램도 같이 죽는다** |

무형 이익에 금액을 붙이지 않습니다 — 붙이는 순간 이 문서의 숫자 규율이 깨집니다.

## 4. 고객이 안 사는 이유 — 정직한 반론 목록

가격을 정하기 전에, 고객 쪽 회의실에서 나올 반론을 먼저 적습니다.

1. **"TPA 리포트는 공짜인데."** — 다른 선반의 물건이지만, 예산 관문에서는 같은 줄에 세워질 것. 프로그램 프레임이 답이지만 그 프레임을 사줘야 성립.
2. **"1년차엔 돈이 더 나가네."** — 사실 (§1.3). 반박하지 않고 인정한 채 파는 것이 유일하게 유지 가능한 자세.
3. **"절감을 증명 못 한다면서."** — 사실. 우리가 스스로 정한 제약이고, 이걸 슬쩍 넘는 영업이 가장 큰 사고 경로.
4. **"스타트업이고 미국 레퍼런스가 0이잖아."** — 사실. PoC 파트너 1곳이 답할 수 있는 유일한 반론.
5. **"직원들이 감시라고 느끼면?"** — 설계로 답할 수 있는 유일한 반론 (개인 비노출·억제·동의 모델). 단, 설계가 아니라 **커뮤니케이션이 실패하면** 설계가 좋아도 진다.

| | B (2,500명) | A (10,000명) | C (25,000명) |
|---|---:|---:|---:|
| 연간 치과 지출 `[산술]` | $2,164,800 | $8,289,600 | $20,394,000 |
| $1 PEPM 구독 | $30,000 | $120,000 | $300,000 |
| 지출 대비 | 1.39% | 1.45% | 1.47% |
| 1년차 추가 청구 `[산술×추측]` | $15,750–31,500 | $63,000–126,000 | $157,500–315,000 |
| 도입 비용(법무·TPA·IT) | **거의 동일** | 동일 | 동일 |

마지막 줄이 구조적으로 중요합니다 — **도입 비용은 고정비에 가깝습니다.** 법무 게이트 여섯은 회사 크기와 무관하게 여섯이고, TPA 연결도 한 번입니다. 그래서 **작은 회사일수록 도입 비용이 구독료 대비 커지고**, 250명 하한(억제 산술)에 이어 여기서도 **작은 고객이 불리한 두 번째 이유**가 나옵니다. 첫 고객은 작을수록 좋다는 통념이 다시 한 번 뒤집힙니다.

## 6. 이 분석이 가격 결정에 말하는 것

1. **절감 기반 가격은 불가.** 증명을 스스로 거부했다 — 가격의 서사는 복지 + 근거 + 가시성이어야 한다.
2. **완료당 과금 금지.** 발생 확인에 과금하면 귀속 문제가 가격을 무너뜨린다. 축은 참여 또는 좌석.
3. **1년차 총비용(구독 + 추가 청구 ≈ 지출의 2–3%)을 먼저 말하는 쪽이 이긴다.** 고객 분석가가 먼저 찾아내면 신뢰가 죽고, 우리가 먼저 말하면 정직함이 차별점이 된다.
4. **PoC 파트너 인터뷰에서 물을 것:** 이 프로그램은 어느 예산 항목에서 나오는가 · PEPM 얼마부터 성과 증빙을 요구할 것인가 · 1년차 청구 증가를 CFO 에게 어떻게 설명할 것인가 · 도입에 법무·IT 시간을 실제로 얼마나 쓸 수 있는가.
5. **미검증 목록:** 예산 항목의 존재, 지불 의사, 참여율의 복지 맥락 이전, 장기 회피 효과, 캐리어 인정. **이 다섯이 채워지기 전의 가격은 전부 가설이다.**
